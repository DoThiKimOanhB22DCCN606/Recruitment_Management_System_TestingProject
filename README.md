# Recruitment Management System - SQA Repository

## Overview
This repository contains the Software Quality Assurance (SQA) documents and design reports for the **Recruitment Management System** project at the Posts and Telecommunications Institute of Technology. The system is built to automate the end-to-end recruitment process via a Web platform, supporting tasks from posting jobs, screening CVs, and scheduling interviews to managing dynamic approval workflows and sending offer letters. This repository focuses on storing test plans, scenarios, and test results to ensure the quality and stability of the entire project.

## Technologies Used
The system is developed based on a modern Microservices architecture, separating business domains into independent services.

| Layer | Technologies Applied |
| :--- | :--- |
| **Frontend** | ReactJS, Firebase Hosting |
| **Backend** | Java Spring Boot, Spring Cloud Gateway |
| **Database** | MySQL |
| **Communication & Storage** | Apache Kafka, Socket.IO, Cloudinary |
| **Infrastructure & Deployment**| Docker, Docker Compose |
| **Testing Tools** | JUnit, Postman, Apache JMeter, Selenium |

## Repository Structure
The repository includes the following detailed test reports and documents:

*   **Báo cáo Đồ án Quản lý tuyển dụng.docx**: System analysis and design document, database architecture, and final project report.
*   **9.docx**: The detailed Software Quality Assurance (SQA) Plan of the team.
*   **9_review.xlsx**: Meeting minutes and review checklists for specifications, design, and source code.
*   **9_unit_test.xlsx**: Unit Test scenarios and results for Backend services.
*   **9_system_test.xlsx**: System Test scenarios and results based on equivalence partitioning, boundary value analysis, and decision tables.
*   **9_tool_test.xlsx**: Performance testing results using JMeter and API testing results using Postman.
